Ce qui ne se convertit pas

Certains termes ne décrivent pas une couleur calculable. Le site ne leur invente donc pas de valeur.

Nuanciers propriétaires

Pantone (PMS), RAL, NCS, Munsell, DIC, TOYO sont des catalogues d’échantillons physiques (encres, peintures). Il n’existe aucune formule pour passer d’un HEX à une référence de ces catalogues : il faut leurs tables officielles, souvent sous licence. Les « convertisseurs » en ligne donnent la correspondance la plus proche, avec une marge d’erreur notable.

Profils ICC

Un profil ICC (Coated FOGRA39, Euroscale…) décrit le comportement d’une imprimante ou d’un écran précis. Le CMJN affiché plus haut est une conversion mathématique sans profil. Pour un rendu d’impression fidèle, fais la conversion dans Photoshop, Illustrator ou InDesign avec le profil de ton imprimeur.

Matrice de Bayer

C’est un filtre physique posé sur le capteur des appareils photo. Il capte du rouge, du vert ou du bleu selon le photosite, puis l’image est reconstruite par dématriçage. C’est un procédé d’acquisition, pas un format de couleur.

Sous-échantillonnage (4:4:4, 4:2:2, 4:2:0)

Cette technique stocke la chrominance (Cb/Cr) à une résolution plus faible que la luminance. Elle porte sur un groupe de pixels, pas sur une couleur isolée. Les valeurs YCbCr d’un pixel sont données dans la section Vidéo.

Calculs en local selon CSS Color Module 4 (D65, adaptation de Bradford pour D50). Aucune donnée envoyée.
